wissi-viz

Slides

    Click a slide to show it in the active pane. Drop files anywhere to open them.

    Open a whole-slide image

    SVS, CZI, OME-TIFF, NDPI and more, brightfield or fluorescence. Add a cell table (CSV, Parquet, AnnData) or annotations (GeoJSON, HALO XML) on top.

    Draw & SAM

    SAM: checking…
    SAM works in any pane: click an object (shift-click to exclude a part, drag a box), check the cyan outline, then Accept. Drawing tools save to the same layer and class.

    Layers of the active slide

      Measure regions

      CSV
      Shape, stain / channel intensity, texture; with cells: counts, density, composition, diversity, neighbour distances, contacts and clustering — one row per region.

      Connect to a tile API

      Paste the service description (JSON: base URL, auth header, where the image list, metadata and tiles are), or the path of a .json file on the computer running wissi-viz. The images appear in the slide list; nothing is downloaded until a pane shows one.
