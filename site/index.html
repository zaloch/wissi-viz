Whole-slide images,
on the GPU.

A fast viewer and spatial-analysis toolkit for brightfield and fluorescence histology. Up to 32 slides and millions of cells at once, in any web app, in NiceGUI, or as a desktop app.

Get started View on GitHub
uv tool install "wissi-viz[desktop]"

Everything a slide review needs

The browser does the drawing; the Python server decodes and caches. Nothing to compile, no plugins.

1–32 panes, one GPU canvas

Synchronised pan and zoom in pixels or microns, adaptive resolution while moving, smooth even without a GPU.

Every common format

SVS, CZI, OME-TIFF, NDPI, VSI, ZVI, DICOM, SCN, AFI, plus PathCore, HALO Link and any HTTP tile API through connectors.

Millions of cells

QuPath, HALO, CellProfiler, GeoJSON, label masks and AnnData. Aggregated dots far out, outlines up close, coloured by class or any measurement.

Spatial analysis

Proximity, invasive margins, composition, density hotspots, Ripley's K/L/g, co-location, neighbourhoods, Moran's I and H-score: a table, an overlay and a chart each.

Fluorescence and stains

Up to 8 16-bit channels composited on the GPU with per-channel contrast, and brightfield stain deconvolution (H, E, DAB).

Ready for production

Byte-budgeted caches, memory-mapped object layers, an integration probe, a load tester, and permissive licences only.

Use it your way

The same viewer in four hosts. Install with uv or pip.

shell
# install once (Windows, macOS, Linux)
uv tool install "wissi-viz[desktop]"

# open the app, or open files directly
wissi-viz-app
wissi-viz desktop slide.svs cells.csv

# add it to the Start menu / Applications / app menu
wissi-viz desktop --install-shortcut
html
<script type="module" src="/wissi-viz/static/index.js"></script>

<wissi-viz api="/wissi-viz" slides="case1,case2" sync="all"></wissi-viz>
python
from nicegui import ui
from wissi_viz.nicegui import WissiViz, configure

configure(cache_dir='/var/cache/wissi-viz')

@ui.page('/')
def index():
    WissiViz(['/data/case1.svs', '/data/case1_if.czi'], sync='all')

ui.run()
shell
uv tool install "wissi-viz[server]"
wissi-viz serve /data/slides --port 8010 --cache-dir /var/cache/wissi-viz
# open http://127.0.0.1:8010/
